🏛️ 7 Maravilhas do Mundo Moderno — Quick Sort em Python

Este projeto foi desenvolvido com o objetivo de demonstrar, de forma visual e interativa, o funcionamento do algoritmo de ordenação Quick Sort, utilizando como tema as 7 Maravilhas do Mundo Moderno.

A aplicação foi criada em Python, utilizando a biblioteca Tkinter para a interface gráfica e a biblioteca Pillow (PIL) para manipulação das imagens. O usuário pode interagir diretamente com os cards das maravilhas, tentando organizá-las em ordem cronológica, do monumento mais antigo ao mais recente. Após a tentativa, o sistema verifica se a ordem está correta e também permite visualizar o algoritmo Quick Sort realizando automaticamente o processo de ordenação.

O projeto busca unir conceitos de algoritmos e estruturas de dados com uma abordagem mais dinâmica e visual, facilitando a compreensão do funcionamento do Quick Sort através de animações, separação por pivô e reorganização dos elementos.

🚀 Funcionalidades
Interface gráfica interativa
Arrastar e soltar os cards manualmente
Verificação automática da ordem cronológica
Animação completa do algoritmo Quick Sort
Separação visual entre elementos menores e maiores que o pivô
Exibição dos anos das maravilhas
Embaralhamento automático das posições

▶️ Como Executar o Projeto
Clone o repositório:

cd Python_QuickSort
Instale a biblioteca Pillow:
pip install pillow

python main.py
